# Enterprise GraphRAG with Regulatory Citation Lineage

Hybrid **Property-Graph + Vector Retrieval** (`NetworkX` + `Neo4j` Cypher adapter + verifiable citation lineage) over public EU regulatory texts (**EU AI Act 2024/1689** & **GDPR**).

## Quickstart

```bash
pip install -r requirements.txt
PYTHONPATH=. pytest tests -v
```
